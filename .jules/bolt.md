
## 2025-05-14 - [Async Optimization in Dart]
**Урок (Learning):** В Dart функции async выполняются синхронно до первого await. Оптимизация тяжелых вычислений (например, toList() для больших списков) требует явного освобождения событийного цикла через Future.microtask, иначе UI все равно будет блокироваться.
**Действие (Action):**Всегда использовать await Future.microtask(() {}) перед выполнением O(N) операций в обработчиках нажатий или провайдерах, чтобы гарантировать плавность интерфейса.

## 2024-04-23 - Оптимизация 60 FPS анимаций в Waveform
**Урок (Learning):** Использование `setState()` внутри `Ticker` для анимации волны в `LiveWaveformProgressBar` приводило к постоянному (до 60/120 FPS) перестроению всего дерева виджетов. Для простых CustomPaint анимаций, не влияющих на компоновку (layout), это избыточно и тратит ресурсы процессора.
**Действие (Action):** Всегда использовать связку `ValueNotifier` + `ValueListenableBuilder` (или `ListenableBuilder`) вокруг `CustomPaint`, чтобы изолировать ребилд исключительно для холста, избегая ненужной перерисовки соседних виджетов (например, жестов или текстовых таймеров).
