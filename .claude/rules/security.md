# Безопасность: правила из `.jules/sentinel.md`

Все четыре правила уже реализованы. Задача — не сломать их при правках.

1. **Имена файлов из сети и импорта — только через `p.basename()` и белый список символов.** Без этого `../` в id или имени файла позволяет записать файл за пределы папки приложения. Сейчас так сделано в `ImporterService` для пути трека и обложки: `p.basename(...).replaceAll(RegExp(r'[^a-zA-Z0-9\.\-\_]'), '_')`; так же `UpdateAsset.fileName` чистит имя файла обновления. Свои файлы копируются под id из хэша (`local_<hex>`, `local_tags.dart`), имя исходного файла в путь не попадает.
2. **Импорт принимает только `http://` и `https://`.** Проверка стоит в начале `ImporterService.importFromUrl`. Не убирать её и не обходить новыми точками входа, иначе пройдут `file://` и другие схемы.
3. **Сырые исключения пользователю не показывать.** `e.toString()` может раскрыть пути и стектрейсы. Паттерн: `debugPrint('…: $e')` в лог и общее русское сообщение в UI («Произошла ошибка…»). Так сделано в `ImporterService` и в обновлениях (`UpdateInstallException.message` — готовый текст для пользователя, остальное уходит в лог).
4. **Имена плейлистов очищаются:** `trim()`, удаление управляющих символов `[\x00-\x1F\x7F-\x9F]`, пустое имя заменяется на `'Unnamed Playlist'` (`PlaylistDatabase.createPlaylist` / `renamePlaylist`). Новые поля с пользовательским текстом — так же: теги своих файлов (`local_tags.dart`) и названия из API Яндекс Музыки (`yandex_music.dart`) чистятся от управляющих символов.

Что **не** является уязвимостью: подмена `X-Real-IP` в `NetEaseProvider` (см. `dependencies.md`).

## Обновления

Установка обновлений — самое опасное место приложения: оно запускает скачанный исполняемый файл. Проверки в `lib/features/updater/` не ослаблять:
- подпись манифеста Ed25519 по ключам из `kUpdateSigningKeys`; неизвестный `kid` — отказ;
- адреса файлов только по https;
- размер не больше `UpdateAsset.maxSize` и точное совпадение SHA-256 перед установкой;
- обновление только на сборку новее текущей (`build`).

На Windows это единственная защита от подменённого установщика: подписи кода у exe нет. Подробности и хранение ключа — `release.md`.

## Репозиторий публичный

С 2026-09-11 репозиторий открыт. Никаких секретов ни в коде, ни в истории git: keystore, `key.properties`, токены, ключи API, пароли, приватный ключ подписи манифеста обновлений. Всё, что вкомпилировано в приложение (`const`-строки, ассеты), тоже публично: из APK или exe это достаётся за минуты. Публичный ключ в `update_keys.dart` секретом не является. Токен бывшей телеметрии уже утёк — см. `known-issues.md`.
