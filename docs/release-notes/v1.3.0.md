**Protogenix 1.3 — альбомы и плейлисты Spotify.** Вставь ссылку на альбом или плейлист — Protogenix разберёт список, найдёт каждый трек на YouTube, скачает и соберёт плейлист с тем же названием. У больших плейлистов есть предел: без входа в аккаунт Spotify отдаёт чужим приложениям только первые 99 треков. Приложение говорит об этом сразу, ещё до импорта, и объясняет почему.

## ✨ Новое

### 🎵 Альбомы и плейлисты Spotify
- Раньше импорт понимал только ссылку на отдельный трек Spotify, а на альбом и плейлист отвечал ошибкой. Теперь берёт и их: каждый трек ищется на YouTube по названию, исполнителям и длительности — без каверов, концертов и чужих версий — и складывается в плейлист с названием альбома или плейлиста.
- **Альбом скачивается целиком.** У плейлиста — первые 99 треков: столько Spotify отдаёт приложениям без входа в аккаунт. Об этом написано прямо под полем ссылки, а «Почему?» рядом объясняет причину простыми словами. Большой плейлист можно разбить на несколько поменьше.
- Треки, которые уже есть в медиатеке, второй раз не ищутся и не качаются: повторный импорт той же ссылки просто дополняет плейлист.
- Импорт идёт в фоне: шторку можно закрыть, музыка играет, прогресс виден на плашке. «Остановить» останавливает между треками, а прерванный импорт приложение предложит продолжить при следующем запуске.

## 🛠 Исправлено
- Ссылка Spotify, которую импорт не может скачать (исполнитель, подкаст), теперь получает понятное сообщение вместо «неизвестный формат ссылки».
- Длинные объяснения в окнах приложения прокручиваются, а не обрезаются на невысоких экранах.
- Плашка импорта показывает три строки вместо двух — итог с длинным перечислением больше не обрывается.

## 📥 Какой файл скачать

Если Protogenix уже стоит, скачивать ничего не нужно: приложение само предложит обновиться.

| Устройство | Файл | Размер |
|---|---|---|
| 📱 Android — почти любой современный телефон | `protogenix-android-arm64-v8a.apk` | ≈ 37 МБ |
| 📱 Android — старый 32-битный телефон | `protogenix-android-armeabi-v7a.apk` | ≈ 35 МБ |
| 📱 Android — не знаешь, какой у тебя, или APK выше не ставится | `protogenix-android-universal.apk` | ≈ 107 МБ |
| 💻 Windows 10 / 11 (64-бит) | `Protogenix-Setup.exe` | ≈ 27 МБ |

`protogenix-update.json` скачивать не нужно — это служебный файл для автообновления.

## 🛠 Установка

**Android 7.0 и новее**
1. Скачай APK на телефон и открой его.
2. Android попросит разрешить установку из браузера или файлового менеджера — разреши. После установки разрешение можно выключить обратно.
3. Если Android пишет, что приложение несовместимо, — значит, APK не под твою архитектуру: возьми `universal`.

**Windows 10 / 11**
1. Запусти `Protogenix-Setup.exe`. Права администратора не нужны: программа ставится в профиль пользователя.
2. Если появится «Система Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**. Установщик пока не подписан сертификатом, поэтому SmartScreen его не знает.
3. Удаляется программа через «Установленные приложения» в Параметрах Windows. Медиатека при этом сохраняется.
